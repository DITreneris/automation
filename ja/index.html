AIに日々の作業の30〜50%を任せる

定型テンプレート付きの演習8本。数分で結果が出ます。

対象：管理職、専門職、コンサルタント、フリーランス。

最初のプロンプトを使う

得られること

30分で基本のAIワークフローができます：

  • 週に3〜5時間の節約
  • ミスのリスクを最大6倍低減
  • 標準テンプレート8本
  • 場当たりなプロンプトではなく、明確な自動化ロジック

このライブラリの使い方 ステップあたり約3〜5分

  1. プロンプトを選び、テキスト下の「プロンプトをコピー」をタップ。一度でコピーできます。パソコンではテキストを選択して Ctrl+C / Cmd+C も使えます。
  2. ChatGPT、ClaudeなどのAIツールに貼り付けます。
  3. プロンプト内の [COMPANY] は自社またはクライアント企業名に、[MY ROLE] はあなたの役職に置き換えてください。AIの役割（例：「批判的なアナリスト」）は既に指定されているため変更不要です。

進捗：0 / 8

1
基礎
約3〜5分

AIコンテキスト診断

AIが組織について何を知り、どこで誤りやすいかを確認する

META: あなたは批判的なビジネスアナリストです。目的：AIが組織について実際に何を知っているのか、どこに確認が必要かを明らかにする。

INPUT: 企業 [COMPANY]。公開情報と一般的な市場知識のみに基づき、あなた（AI）がこの企業をどう理解しているかを説明してください。構成：1) 確実に言えること 2) 推測していること 3) 情報が不足しており誤っている可能性がある点。最後に必ず「以下はユーザーによる確認が必要です。」と明記してください。

OUTPUT: 結果：短く構造化された回答。AIがどこで間違えやすいか、次に進む前に何を確認すべきかが明確になる。

次へ：組織ポートレート →

使う前に

こんなとき：組織の分析を始める／AIが会社について何を知っているか確認したい／コンテキスト付きでAIを使い始めたい。

事前に置き換え：

  • [COMPANY] → 自社またはクライアント企業名（例：株式会社サンプル）

やること：上のプロンプト本文をコピーして、ChatGPTやClaudeなどに貼り付けます（アンケートではありません）。

なぜ重要か

AIの思い込みや誤判断を減らし、組織について何を知っているかがはっきりします。

開くとプロンプトを表示。約5分で構造化した会社プロフィール

INPUT: 企業 [COMPANY]。以下を分析・要約してください：概算規模（従業員数、売上）；主な事業領域；経営・組織モデル；この業界で典型的な課題。簡潔に、構造化して書くこと。推測している箇所は明示してください。

OUTPUT: 結果：他のプロンプトでコンテキストとして使える組織ポートレート。

事前に置き換え：

  • [COMPANY] → 自社またはクライアント企業名（例：株式会社サンプル）

やること：上のプロンプト本文をコピーして、ChatGPTやClaudeなどに貼り付けます。

3
役割
約3〜5分

組織での役割

AIが穴埋めする前に、役割の目的と影響を明確にする

▾ 
META: あなたは組織設計コンサルタントです。目的：ユーザーの組織内での役割（目的・責任・影響）を明確にする。

INPUT: 役割 [MY ROLE]、企業 [COMPANY]。組織分析に基づいて、この役割を説明してください。含める：役割の主要目的；5〜7個の主要責任；意思決定レベル（オペレーション・戦術・戦略）；誰に報告し、日々誰と連携するか。理論は不要、短く具体的に。

OUTPUT: 結果：明確な役割記述。次のステップの参照として使える。

次へ：職務記述書 + KPI →

使う前に

こんなとき：役割を明確にしたい／新しい会社で始める／職位の参照が欲しい。

事前に置き換え：

  • [COMPANY] → 自社またはクライアント企業名（例：株式会社サンプル）
  • [MY ROLE] → あなたの役職・職能名（例：カスタマーサクセスマネージャー）

やること：上のプロンプト本文をコピーして、ChatGPTやClaudeなどに貼り付けます。

結果

明確な役割記述が得られます。次のステップの参照に使えます。

5
プロセス
約3〜5分

中核の業務プロセス

時間の80%がどこへ行くかを把握。AI最適化ステップの入力になる

▾ 
META: あなたは業務プロセスアナリストです。目的：最重要の業務プロセス5つ（パレート80/20）を特定し、時間とエネルギーの使いどころを明らかにする。

INPUT: 役割 [MY ROLE]、企業 [COMPANY]。この役割が実際に行っている最重要プロセスを5つ挙げてください。各プロセスについて：目的；主なステップ；関係者；詰まりやすいポイント。説明は20%、具体的な作業の列挙を80%。

OUTPUT: 結果：プロセス一覧。次のステップ（6）で、AIのインパクトが大きい箇所を見つけるために使う。

AI活用
約3〜5分

AIによる支援と最適化

プロセスマップを、時間を節約する具体的なAIショートカットに変換

▾ 
META: あなたはAI導入コンサルタントです。目的：プロセスを評価し、ChatGPTなどのAIツールで改善する具体案を提示する。

INPUT: （すでに記述した）プロセスを評価し、8〜10個の改善アイデアを出してください。各アイデアについて：AIが何をするか；どのプロセス部分が楽になるか；実際の効果（時間・品質・コスト）；実装難易度（簡単・普通・難しい）。非技術者にも分かる言葉で。

OUTPUT: 結果：週あたり数時間を節約できる、8〜10個の具体アイデア。

シミュレーション

危機シナリオのシミュレーション

本番前にAIでプレッシャー下の判断をリハーサル

▾ 
META: あなたは戦略計画コンサルタントです。目的：危機的状況をシミュレーションし、行動計画を用意して、プレッシャーと不確実性に備える。

INPUT: 企業 [COMPANY]、役割 [MY ROLE]。この役割に直接影響する「危機的状況」を想定してください。含める：現実的なシナリオを2つ；最初の14日間の行動計画；AIがどう支援できるか；主要リスクと成功基準。
